# 🌱 AgroGuid

**AgroGuid — автоматизована інформаційна система довідника агронома з картографією полів.**

AgroGuid — це настільна програма для Windows, призначена для обліку сільськогосподарських полів, перегляду їхнього розташування на інтерактивній карті, отримання довідкової інформації про сільськогосподарські культури та ведення історії виконаних операцій.

Програма розроблена з використанням **C# та .NET MAUI** і працює з локальною базою даних **SQLite**, тому для збереження інформації не потрібні окремий сервер або підключення до PostgreSQL.

## 📥 Завантаження та встановлення

Для встановлення AgroGuid не потрібно завантажувати Visual Studio або налаштовувати базу даних.

1. Перейдіть у розділ **Releases** цього репозиторію.
2. Відкрийте останню доступну версію.
3. Завантажте файл `AgroGuidSetup.exe`.
4. Запустіть інсталятор.
5. Виберіть мову та дотримуйтесь інструкцій майстра встановлення.
6. Після встановлення запустіть AgroGuid через меню «Пуск» або ярлик на робочому столі.

**Завантажити AgroGuid:** [GitHub Releases](../../releases)

## 🗺️ Основні можливості

### 1. Карта полів

Інтерактивна карта для роботи із сільськогосподарськими ділянками.

- Перегляд географічного розташування полів.
- Відображення звичайної та супутникової карти.
- Створення нових земельних ділянок.
- Редагування меж наявних полів.
- Видалення земельних ділянок.
- Автоматичний розрахунок орієнтовної площі поля в гектарах.
- Збереження координат і характеристик полів.
- Пошук земельних ділянок за назвою.
- Перегляд інформації про вибране поле.

### 2. Довідник агронома

Інформаційний каталог сільськогосподарських культур.

- Перегляд переліку культур.
- Пошук культур за назвою.
- Фільтрація за категоріями.
- Ознайомлення з характеристиками культур.
- Перегляд особливостей вирощування.
- Відображення тематичних зображень культур.

Довідник містить інформацію про пшеницю, кукурудзу, соняшник, сою, ріпак, ячмінь та інші культури, представлені в базі даних.

### 3. Історія діяльності

Розділ для перегляду подій, пов'язаних із роботою користувача.

- Збереження історії створення полів.
- Фіксація редагування земельних ділянок.
- Облік видалення полів.
- Перегляд дати та опису операцій.
- Пошук записів історії.
- Фільтрація подій.

## 👤 Облікові записи

AgroGuid підтримує локальну систему авторизації.

Користувачі можуть створювати облікові записи, входити до програми та працювати зі своїми даними.

Інформація зберігається локально на комп'ютері в базі даних SQLite.

## 🔒 Збереження даних

AgroGuid використовує локальну базу SQLite.

Дані користувачів, земельних ділянок та історії зберігаються на комп'ютері користувача.

Для роботи з базою даних не потрібно встановлювати PostgreSQL або запускати окремий API-сервер.

**Увага:** видалення локальних даних програми може призвести до втрати збереженої інформації. Рекомендується створювати резервні копії важливих даних.

## 🚀 Запуск із вихідного коду

Для розробників, які бажають відкрити проєкт у Visual Studio:

1. Встановіть Visual Studio 2026 із підтримкою .NET MAUI.
2. Клонуйте репозиторій.
3. Відкрийте проєкт `AgroGuid.csproj`.
4. Відновіть NuGet-пакети.
5. Виберіть платформу **Windows Machine**.
6. Запустіть проєкт клавішею **F5**.

Для звичайного використання програми ці дії не потрібні — достатньо інсталятора.
